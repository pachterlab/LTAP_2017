# LTAP_2017

This repository is an alias for **[pachterlab/PROBer_paper_analysis](https://github.com/pachterlab/PROBer_paper_analysis)**, which contains the code and analysis for:

Bo Li, Akshay Tambe, Sharon Aviran, and Lior Pachter. **[PROBer Provides a General Toolkit for Analyzing Sequencing-Based Toeprinting Assays](https://doi.org/10.1016/j.cels.2017.04.007)**. *Cell Systems* 4(5), 568–574.e7 (2017).

**[Go to the code and documentation →](https://github.com/pachterlab/PROBer_paper_analysis)**

The alias follows the Pachter Lab convention of author last-name initials in order followed by the publication year. The original PROBer_paper_analysis repository remains the source of the code and retains its existing URL.
